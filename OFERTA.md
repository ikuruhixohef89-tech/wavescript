# Политика конфиденциальности

## Что обрабатывается

Записи, которые вы расшифровываете, не покидают ваш компьютер и продавцу не передаются.

При покупке и активации лицензии сохраняются:

- числовой идентификатор вашего аккаунта Telegram — чтобы выдать ключ и показать ваши лицензии;
- обезличенный идентификатор компьютера (хэш) и версия программы — чтобы считать занятые места;
- сведения о платеже: сумма, дата, номер счёта.

Имя, почта, номер телефона и данные карты продавцом не собираются и не хранятся. Платёжные данные обрабатывает Robokassa по собственным правилам.

Данные хранятся в базе данных сервиса Supabase (серверы в Германии) и обрабатываются сервером на платформе Vercel.

Данные используются только для выдачи и проверки лицензий и хранятся, пока действует лицензия. Третьим лицам не передаются, кроме случаев, предусмотренных законом.
